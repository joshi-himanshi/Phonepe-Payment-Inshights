📱 PhonePe Payment Insights Dashboard

An interactive Payment Analytics Dashboard built using Microsoft Power BI to analyze digital payment transactions, user activity, transaction trends, and payment performance.

📊 Dashboard Preview

🎯 Project Overview

The PhonePe Payment Insights Dashboard provides a visual overview of digital payment performance through interactive charts, KPIs, and data visualizations.

The dashboard helps understand transaction patterns, user engagement, payment trends, and customer behavior.

📌 Key Performance Indicators (KPIs)

- Total Transactions: 300K
- Total Transaction Value: 3.47 Billion
- Unique Users: 108K
- Successful Rate: 96.00%

📈 Dashboard Features

- Transaction Over Time: Analyzes monthly transaction trends and transaction value.
- Age Segment Contribution: Visualizes transaction contribution across different age groups.
- Weekday vs Weekend Usage: Compares payment activity during weekdays and weekends.
- Service-wise Transaction Value Analysis: Displays transaction value across different payment services.
- Top 5 Users: Highlights the top five users based on transaction value.
- Interactive Filters: Enables filtering data using available slicers.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation

💡 Key Insights

- Monitors overall transaction volume and transaction value.
- Evaluates payment success rate.
- Identifies monthly transaction patterns.
- Analyzes customer activity across age segments.
- Compares weekday and weekend payment behavior.
- Highlights top users based on transaction value.
